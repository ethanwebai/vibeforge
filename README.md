# Vibeforge site

Files: index.html, work.html, process.html, contact.html, play/stadium-sprint.html

Put all of these in one GitHub repo (keep the play folder) and turn on GitHub Pages
(Settings > Pages > Deploy from a branch > main > / (root)).

The contact form posts to Formspree (https://formspree.io/f/xbgodkwg). The first test
submission asks you to confirm by email. It only sends from the live site, not from the preview.

To add a project: edit the PROJECTS list in the script at the bottom of work.html and index.html
(or ask Claude to add it and rebuild).
